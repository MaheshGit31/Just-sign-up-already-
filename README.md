A terrible sign in page that forces you to do random stuff to sign up. (Gaurunteed crashout ✌️✌️)

### "Just Sign Up" is a very interesting type of sign-in page. It is made to make you not sign up. That is the whole goal of the website: to try to force you to not sign up. The whole thing functions on HTML with math, and some CSS to make it look nice. 

### You can try the site for yourself at https://justsignup.maheshofficial.uk , or you can "deploy" it yourself by downloading the repo as a folder and opening the index.html to have it work.
